# FlowPay Privacy Policy — DRAFT, NOT PUBLISHED

This draft requires legal/operational review and contact details before publication. It must not be represented as an effective public policy.

FlowPay is a personal cash-flow and bill-coverage application. If you choose to connect a test financial institution through Plaid Sandbox, FlowPay may process account identifiers, balances and transaction information to provide banking features. FlowPay also processes account authentication information, consent records and limited security events.

Bank connectivity uses Plaid; authentication uses Supabase; application infrastructure uses Render and Cloudflare. Information may be processed by these service providers as needed to operate the application. **Verify the full provider list and actual data flows before publishing.**

Users can grant or withdraw bank-data permission. Withdrawing permission stops further protected banking operations but does not automatically erase stored bank data or revoke all previously connected tokens. Disconnecting a bank or deleting an account is a separate action.

Security controls include authenticated access, permission checks and encrypted banking-token storage. No online system can be guaranteed absolutely secure.
